# หลักสูตร Crystal Programming Language
## จากพื้นฐานสู่ระดับมืออาชีพ

Crystal เป็นภาษาโปรแกรมที่มีไวยากรณ์คล้าย Ruby แต่ทำงานเร็วเทียบเท่า C/C++ เนื่องจากถูก compile เป็น native binary
